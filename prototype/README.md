# 온결 셀프상표 — 프로토타입

변리사가 대리인으로 참여하는 상표출원 플랫폼의 체험용 웹사이트입니다.
고객은 신청·위임장 확인·모의 결제를 진행하고, 사무소는 서류 검토부터 자동 입력·제출 승인·관납료 기록까지 확인할 수 있습니다.

사무소·인물·상표·번호·요율은 모두 가상 정보입니다. 실제 특허청·PG·본인인증·AI·알림톡과 연결하지 않습니다. 실제 개인정보·카드·인증서 정보를 입력하지 마세요.

## 열기

`index.html`을 일반 브라우저에서 엽니다. 웹 서버나 빌드 과정 없이 정적 호스팅에서도 동작합니다.

- 첫 방문은 비로그인 상태입니다.
- 고객은 상단 「로그인」, 사무소는 「사무소 로그인」에서 시작합니다.
- 로그인 화면의 체험 계정을 누르면 이메일·비밀번호가 입력됩니다. 「로그인」을 눌러 진입합니다.
- 체험 데이터 초기화는 고객·사무소 로그인 화면에서 사용할 수 있습니다.
- 작성 내용·업로드 이미지·처리 이력·설정·로그인 상태는 현재 브라우저의 localStorage에 저장하여 새로고침 후에도 이어서 볼 수 있습니다.
- 로그아웃하면 해당 로그인 상태를 지우고, 고객별 작성 중 신청서는 보관합니다. 다른 고객에게는 이전 고객의 신청서가 표시되지 않습니다.
- 로그인 화면의 「체험 데이터 초기화」는 저장 자료와 고객·사무소 로그인 상태를 함께 초기화합니다. 테마 선택은 유지합니다.

## 확인할 수 있는 흐름

### 고객

- 서비스 소개·요금 계산기·FAQ
- 로그인·회원가입·로그아웃
- 출원인 → 상표 → 지정상품 → 도장·서명 → 위임장 확인 → 모의 결제의 6단계 신청
- 문자 상표 생성, 이미지 변환, 샘플 도장 사진의 배경 정리
- 지정상품 예시 목록 안에서 후보 추천·선택
- 신청 중간 저장과 새로고침·재로그인 후 이어쓰기
- 카드 결제·가상계좌 발급과 입금 통지 모의 처리
- 내 출원·진행 기록·위임장·등록료 모의 결제·알림

### 사무소

- 대시보드·출원 접수·검색·상태별 필터
- 출원 상세의 신청 정보·위임장·자동화 기록·결제·납부·이력 탭
- 자동 입력·대조·승인·인증·제출·결과 수집 모의 흐름
- 입력 오류 사례 `C050` 재처리, 인증 대기 `C052`, 제출 결과 미확인 `C051` 판정
- 관납료 납부 기록·고객 결제·환불·등록 단계 관리
- 회원 정보 열람 및 감사 이력, 역할별 작업 권한
- 위임장 양식 새 버전·요율표·대리인 설정

상시 노출되던 「기능 살펴보기」 패널과 고객 화면의 사무소 자동 로그인 동선은 제거했습니다. 오류 사례는 사무소 목록에서 직접 선택합니다.

## 보완한 동작

- 보호된 관리자 경로는 사무소 로그인 후 진입합니다.
- 고객은 다른 고객의 등록료·위임장에 접근할 수 없습니다.
- 개인정보 열람 후 화면 이탈·계정 변경 시 다시 마스킹합니다.
- 양식 최대 글자 수 0·음수·빈 값 입력에 의한 반복 처리 멈춤을 방지합니다.
- 자동 입력 도중 취소하면 예약 작업을 정리해 취소된 출원이 다시 진행되지 않게 합니다.
- 인증 재개 시에도 승인 버전과 현재 버전을 대조합니다.
- 대리인 설정을 바꿔도 과거 위임장은 생성 당시 데이터로 조회합니다.
- 제출됨 판정으로 접수번호를 기록해도 출원번호를 임의 생성하지 않습니다.
- 음수 요율·빈 대리인 정보·잘못된 출원번호 저장을 차단합니다.
- 대시보드 최근 7일 수치는 실제 체험 목록의 결제 기록으로 집계합니다.

## 추가 재검토 반영

- 계정 전환·로그아웃 시 화면 상태를 정리하고 고객별 작성 중 신청서는 따로 보관하며, 완료 화면에서도 소유권을 확인합니다.
- 자동 입력에는 상세 주소까지 포함하고, 기존 위임장에 기록된 대리인 코드로 입력합니다.
- 개인정보 열람 권한이 없는 계정에는 위임장 원문과 콘솔·대조표·증적·재처리의 개인정보를 제한합니다.
- 위임장 확인·동의 이후 신청 내용·지정상품·요금·대리인·양식이 바뀌면 재확인 단계로 이동합니다.
- 모바일에서 같은 메뉴를 다시 눌러도 사이드바가 닫히도록 했습니다. 입력란의 최소 너비와 태블릿 메뉴 간격도 조정했습니다.
- 요금 계산기를 다시 열어도 선택 표시와 계산 결과가 일치하도록 했습니다.
- 이미지 읽기·변환 중 고객이나 상표·날인 방식을 바꾸면 이전 처리 결과가 다른 초안에 반영되지 않도록 했습니다. 손상 이미지 안내와 변환본 용량 검사도 추가했습니다.
- 신청 완료 화면에서 빈 초안이 다시 생기던 문제를 수정하고, 중간 저장은 실제 저장 성공 여부에 맞춰 안내합니다.
- 제출 중 연동 PC 연결이 끊기면 제출 확인 대기·납부 보류로 처리합니다. 입력 중 연결 끊김은 주소 오류와 구분해 재처리합니다.
- 출원번호 확인 전 알림 문구와 입력 문자열의 HTML 해석을 보완했습니다.

## 체험 데이터 저장·복원

- 신청서·이미지·결제 및 납부 기록·처리 이력·양식 버전·요율·대리인 설정을 함께 저장합니다. 회원가입한 가상 계정도 다시 사용할 수 있습니다.
- 자동 입력 중 새로고침하면 작업을 중단 상태로 복원하고 사무소에서 명시적으로 재처리합니다. 제출 중 새로고침하면 「제출 확인 대기」로 복원하여 결과 확인 전 중복 제출·납부를 막습니다.
- 저장 공간 부족이나 저장 권한 문제는 화면에 안내하며, 마지막 저장 자료를 유지합니다. 다른 탭에서 자료가 변경되거나 초기화되면 현재 탭의 덮어쓰기를 중단하고 새로고침을 안내합니다.
- 같은 브라우저의 같은 주소에서 이용하는 체험 저장 기능입니다. 다른 기기·브라우저와 동기화하지 않으며, 사이트 데이터 삭제나 비공개 창 종료 시 자료가 사라질 수 있습니다. `file://` 저장 범위는 브라우저에 따라 다를 수 있습니다.
- 실제 개인정보와 비밀번호를 저장하는 용도가 아닙니다. 체험 계정 정보와 입력값은 암호화되지 않은 브라우저 저장소에 보관하므로 가상 정보만 사용하세요.

## 시뮬레이션의 경계

- 전자출원 화면·공동인증서·PG·본인인증·알림은 모두 모의 동작입니다.
- AI는 외부 모델 대신 예시 목록과 규칙으로 추천합니다. 공식 지정상품 목록의 완전한 재현이 아닙니다.
- 상표 이미지 변환·도장 배경 정리는 브라우저 Canvas에서 처리합니다. 파일을 서버로 전송하지 않습니다.
- 위임장은 HTML 미리보기이며 「PDF 저장」은 브라우저 인쇄를 이용합니다. 실제 제출용 PDF 생성 모듈이 아닙니다.
- 양식·번호·인증·요율은 실제 제출 적합성이나 법적 효력을 보증하지 않습니다.
- 계정·권한 검사는 체험 화면의 상태 검증입니다. 서버 인증·서버 권한 검증·암호화 저장을 구현한 서비스가 아닙니다.

## 이미지·디자인

밝은 웜 아이보리·보태니컬 세이지·차콜 톤을 유지합니다. 사진은 우편봉투·문구류 중심의 연출 대신 상표 표장 검토, 출원 서류 준비와 사무소 업무 환경을 보여 주는 이미지 3종으로 교체했습니다. 모든 사진의 로고·화면·서류는 서비스 분위기를 위한 가상 연출이며 실제 기관 화면이나 제출 양식이 아닙니다. 모바일 신청에서는 장식 사진을 감춰 입력에 집중하도록 했습니다.

- `assets/trademark-review-v3.webp` — 1536×1024, 메인·내 출원
- `assets/trademark-documents-v3.webp` — 1536×1024, 소개 섹션·브랜드 카드·신청 요약
- `assets/trademark-office-v3.webp` — 1024×1536, 고객·사무소 로그인·회원가입
- 이전 사진 파일 4종은 보존하며 현재 화면에서는 사용하지 않습니다.
- 프롬프트와 생성 방식: `assets/이미지_제작기록.md`

## 검증

`tests/verify.cjs`와 `tests/storage.cjs`는 jsdom과 @napi-rs/canvas를 사용하는 DOM·상태 검사입니다. 별도 검증 환경에서 두 패키지를 설치하고 Node.js로 실행합니다. 서비스 실행에 이 패키지들은 필요하지 않습니다.

2026-10-27 기준 회귀 검사 45개와 저장·복원 검사 25개, 총 70개 통과. 세부 범위와 미검증 항목은 `검토결과.md`를 참조하세요.

실제 브라우저의 PC·모바일 화면 배치, 터치 서명, 인쇄 출력, 실기관 연동은 이 DOM 검사로 검증하지 않습니다.
